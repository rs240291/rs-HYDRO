# rs-HYDRO
Repository containing materials developed for research in spin hydrodynamics and stochastic hydrodynamics.

# Modeling Λ polarization in Au+Au collisions at 200 GeV using relativistic spin hydrodynamics
The data files related to the work\
Matteo Buzzegoli, Aleksandar Gecić, and Rajeev Singh, "Modeling Λ polarization in Au+Au collisions at 200 GeV using relativistic spin hydrodynamics"\
ArXiv:\
are organized as follows:\

# Fig. 4
#
###########################
Description: The local spin polarization vector components $(P_x, P_y, P_z)$ at mid-rapidity $(y_p = 0)$ as a function of transverse momentum $(p_x,p_y)$ for Au$+$Au collisions at $\sqrt{s_{\rm NN}}=200$ GeV within centrality class $35-45$\% for a $(1+1)$D freeze-out.\
